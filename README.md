# IBM Machine Learning Professional Certificate Portfolio

Code, labs, and data science projects completed for the IBM Machine Learning Professional Certificate, covering EDA, Supervised/Unsupervised Learning, and Deep Learning.

## 🚀 Professional Core Competencies Developed
* **Exploratory Data Analysis (EDA):** Implemented advanced missing data handling, data type corrections (`.astype()`), data formatting, and statistical summary workflows.
* **Supervised Learning:** Engineered predictive pipelines using Linear/Logistic Regression, K-Nearest Neighbors (KNN), Support Vector Machines (SVM), and Decision Trees.
* **Unsupervised Learning:** Implemented cluster analysis via K-Means and Hierarchical methods, along with dimensionality reduction using Principal Component Analysis (PCA).
* **Deep Learning:** Built and trained multi-layer neural network models optimized for predictive accuracy and feature scaling.
* **Web Scraping & APIs:** Automated external data extraction using programmatic pipelines like `BeautifulSoup`, `requests`, and the `nba_api`.


## 🚀 Skills Acquired
- **Data Analysis & Visualization:** Pandas, NumPy, Matplotlib, Seaborn, .
- **Supervised Learning:** Linear/Logistic Regression, KNN, Decision Trees, SVMs, Scikit-Learn (Statistical Modeling & ML).
- **Unsupervised Learning:** K-Means, Hierarchical Clustering, PCA, Recommendation Engines.
- **Deep Learning:** Neural Networks, Computer Vision models, Tensor Flow,  Keras.

## 🗺️ Engineering Roadmap & Track Objectives

The curriculum follows a structured advancement timeline across six specialized engineering modules:

### 1. Exploratory Data Analysis for Machine Learning
* **In-Production Focus:** Database extraction optimization. Implementing relational data streams via memory-efficient chunk boundaries (`chunksize`) to handle high-volume datasets.
* **Milestones:** Native XML element compilation, multi-source array mapping, automated metadata schema checking.

### 2. Supervised Machine Learning: Regression
* **Core Focus:** Continuous numerical modeling, cost-function minimization, and variance management.
* **Milestones:** Regularized modeling architectures (Lasso, Ridge, ElasticNet), residual distribution check validation, and hyperparameter cross-validation optimization.

### 3. Supervised Machine Learning: Classification
* **Core Focus:** Boundary optimization for non-continuous tracking arrays.
* **Milestones:** Multi-class classification trees, Ensemble models, SVM kernel mapping, Precision-Recall tuning.

### 4. Unsupervised Machine Learning
* **Core Focus:** Pattern recognition, anomaly processing, and mathematical feature shrinkage.
* **Milestones:** Distance-based vector splitting, spatial density calculations, coordinate variance matrix reduction.

### 5. Deep Learning and Reinforcement Learning
* **Core Focus:** Neural architectures, weights optimization, and state-action optimization matrices.
* **Milestones:** Dense feedforward propagation structures, loss minimization gradients, automated parameter matching.

### 6. Machine Learning Capstone
* **Core Focus:** Full system deployment.
* **Milestones:** Curating historical datasets, processing analytical features, scoring model architectures, and presenting a professional engineering portfolio piece.
